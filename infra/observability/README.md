# Observability

*[Português](README.pt-BR.md)*

OpenTelemetry traces, metrics and logs from the API, the queue workers, the scheduler and the
classifier, collected by an OpenTelemetry Collector and shown in Grafana. Optional:

```bash
make up-obs        # the stack + Collector, Prometheus, Tempo, Loki and Grafana
make demo          # demo tenant (its tickets feed the SLA and classifier panels)
open http://localhost:3001   # user admin, password GRAFANA_ADMIN_PASSWORD in .env
```

With `make up` telemetry stays off (`TICKO_TELEMETRY=false`) and nothing is sent anywhere.
To keep it on, add `COMPOSE_PROFILES=obs` and `TICKO_TELEMETRY=true` to `.env`. With the
classifier too: `COMPOSE_PROFILES=ml,obs` and `CLASSIFIER_URL=http://classifier:8000`.

```
 api ─┐                                    ┌─▶ Prometheus (metrics, 7 days) ─┐
queue ─┼─ OTLP/HTTP ─▶ OTel Collector ─────┼─▶ Tempo (traces, local)  ───────┼─▶ Grafana (127.0.0.1:3001, login)
scheduler ┤    (internal `obs` network)    └─▶ Loki (logs, 72 h)  ───────────┘
classifier ┘   redaction · delta→cumulative
```

## Why this stack

Prometheus, Tempo and Loki are Grafana's native backends: Grafana can link a log line to its
trace (`trace_id`) and a trace to its logs with no extra plugin. Each runs as one small
container with local storage, which is enough for one machine. The Collector keeps the apps
vendor-neutral (OTLP only) and is the single place to scrub data before storage.

## What is instrumented

| Where | Traces | Metrics |
| --- | --- | --- |
| API (`TraceRequests`) | one server span per request, named by route template | `ticko_http_server_duration_seconds` (method, route, status) |
| Queue (`TraceJobs`) | one span per job, **continuing the request's trace** (`traceparent` in the job payload) | `ticko_queue_job_duration_seconds` (job_name, outcome: processed, released, failed) |
| Outgoing calls (`TraceHttpClient`) | client span per call (method, host, status); `traceparent` sent only to our classifier, never to AI providers | — |
| AI (`MeasuredTextGenerator`) | span per model call with provider, model and token counts (never prompt or answer) | `ticko_ai_llm_duration_seconds` (provider, model, outcome), `ticko_ai_tokens_total` (tenant, type), `ticko_ai_cost_usd_total` (tenant) |
| Suggestions | — | `ticko_ai_suggestions_total` (outcome: ready, insufficient = "I don't know", failed), `ticko_ai_suggestion_reviews_total` (approved, edited, discarded + reason) |
| Classifier | the Python service continues the queue's trace | API side: `ticko_classifier_duration_seconds`, `ticko_classifier_confidence` (task, label, applied), `ticko_classifier_corrections_total` (field, set_by); service side: `ticko_classifier_inference_duration_seconds`, `ticko_classifier_model_confidence`, `ticko_classifier_sanitized_total` |
| Sign-in | — | `ticko_auth_login_failures_total` (tenant) |
| Scheduler, every minute | — | `ticko_tickets_open` (tenant, priority), `ticko_tickets_overdue` (tenant, deadline), `ticko_tickets_unassigned`, `ticko_queue_pending`, `ticko_queue_wait_seconds`, `ticko_queue_failed_recent` |

Logs: every Laravel log line goes to Loki with `trace_id`/`span_id`, after redaction.

**Token cost** is an estimate: tokens reported by the provider (estimated for the offline fake)
× `ticko.ai.prices` (USD per million tokens, configurable with `TICKO_AI_PRICE_*`). Each
suggestion also stores its tokens and cost (`ai_suggestions.input_tokens`, `output_tokens`,
`cost_usd`).

**PHP-FPM detail:** each request is its own process, so PHP exports metrics with *delta*
temporality at the end of each request or job, and the Collector's `delta_to_cumulative`
processor turns them into the cumulative series Prometheus expects. The resource carries no
per-process attributes, so all workers add up into the same series.

## Dashboards and alerts (as code)

Generated by [`grafana/build_dashboards.py`](grafana/build_dashboards.py) (`make obs-dashboards`)
into `grafana/dashboards/*.json`, provisioned read-only in the **Ticko** folder (CI fails if the
JSON drifts from the script):

| Dashboard | Panels |
| --- | --- |
| API health | requests/s, p50/p95 latency (total and by route), 5xx ratio, 403/404 bursts, failed sign-ins, redacted logs linked to traces |
| Queue (Horizon) | jobs/min by job and outcome, p95 duration, failed and released jobs, backlog, wait time, failures in 7 days |
| Tickets and SLA | open by priority, unassigned, past first-response and resolution deadlines, per tenant (`$tenant` variable) |
| AI suggestions | "I don't know" rate, approved/edited/discarded (+ reasons), model p50/p95 and errors, tokens and estimated cost per tenant |
| Classifier | calls and failures, latency (API side and inference), average confidence by task, applied vs kept as suggestion, labels predicted, agents' corrections |

Provisioned alert rules ([`grafana/provisioning/alerting/alerts.yaml`](grafana/provisioning/alerting/alerts.yaml)):
failed sign-in spike (> 20 in 5 min), burst of 403/404 (> 50 in 5 min, possible cross-tenant
probing), AI model errors above 20 %, AI cost above 5 USD/hour, and tickets past their SLA
deadline. No notification channel is configured; add a contact point for your team.

## Security

| Rule | How |
| --- | --- |
| Login required | `GF_AUTH_ANONYMOUS_ENABLED=false`, `GF_AUTH_BASIC_ENABLED=false`, sign-up and org creation off. CI checks that anonymous and basic-auth calls get 401 and that `admin`/`admin` is refused. |
| No default password | `GRAFANA_ADMIN_PASSWORD` is generated by `make env` (40 random characters) and the stack refuses to start without it. |
| Not exposed | Only Grafana publishes a port, on `127.0.0.1` (CI checks). The Collector, Prometheus, Tempo and Loki are on the internal `obs` network with no ports. |
| No secrets or personal data | Laravel redacts every log line and attribute (`App\Support\Telemetry\Redactor`): passwords, tokens, cookies, API keys, the app key, SQL with values, ticket text, e-mails, CPF/CNPJ, cards and phones. Spans carry route templates, never URLs, query strings, headers or bodies; exceptions only their type. The Collector applies a second, independent redaction (`attributes` + `redaction` + `transform` processors). Tests prove it (`tests/Feature/Telemetry`, `tests/Unit/RedactorTest.php`, classifier `tests/test_telemetry.py`) and CI searches Loki for e-mails, CPFs and bearer tokens. |
| Bounded cardinality | Metric attributes are route templates, enums and the tenant slug; never user, ticket or free text. A test fails if any other attribute key or an id-like value appears. |
| Trace context | Incoming `traceparent` headers from browsers are ignored; the trace context is sent only to the internal classifier. |
| Images | Pinned by version and digest; all run as non-root users (Collector 10001, Prometheus nobody, Tempo/Loki 10001, Grafana 472), read-only root filesystems, all capabilities dropped, `no-new-privileges`; Grafana analytics, update checks, news and external snapshots off. |
